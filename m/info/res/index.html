1 Sistemas Operacionais 💻

1.1 Conceitos Fundamentais

  • Hardware vs Software: Hardware é a parte física (o que você chuta). Software é a parte lógica (o que você xinga).
  • Firmware: Software embutido no hardware (ex: BIOS da placa-mãe).
  • Kernel (Núcleo): Coração do Sistema Operacional. Gerencia memória, processador e dispositivos.
  • Shell (Interpretador): Interface entre o usuário e o Kernel. Traduz comandos.

✏️ Notas e Dicas do Professor

1.2 Windows 10: Arquiteturas 32 e 64 bits

  • 32 bits (x86): Gerencia no máximo 4 GB de memória RAM.
  • 64 bits (x64): Arquitetura moderna. Gerencia até 16 Exabytes de RAM. Mais veloz.
  • Compatibilidade: Windows 64 bits roda programas 32 bits. O inverso NÃO ocorre.

1.3 Windows 10: Recursos Nativos

  • Windows Defender: O antivírus nativo. Evoluiu contra malwares.
  • BitLocker: Ferramenta de criptografia de disco. (Versões Pro/Enterprise).
  • OneDrive: Nuvem fortemente integrada ao Windows 10.

1.4 Windows 10: Atalhos de Teclado de Ouro

A tecla com o símbolo do Windows se chama WinKey (Win).

  • Win + D: Mostra ou oculta a Desktop (Área de Trabalho).
  • Win + E: Abre o Explorador de Arquivos.
  • Win + L: Bloqueia (Lock) o computador ou troca de usuário.
  • Win + I: Abre as Configurações do Windows.
  • Win + R: Abre a caixa de diálogo Executar (Run).
  • Alt + Tab: Alterna entre janelas abertas.

✏️ Notas e Dicas do Professor

1.5 Linux (SUSE): Princípios

  • Open Source: Código-fonte aberto. Modificável e distribuível.
  • Case Sensitive: O Linux diferencia Maiúsculas de Minúsculas. Prova.pdf ≠ prova.pdf.
  • Multitarefa Preemptiva e Multiusuário: Vários usuários sem travar.

1.6 Linux: Estrutura de Diretórios (FHS)

  • / : Diretório RAIZ.
  • /home : Arquivos pessoais dos usuários comuns.
  • /root : Diretório do Superusuário.
  • /etc : Arquivos de configuração global.
  • /bin : Binários essenciais (comandos básicos).

2.2 Word: Atalhos Brasileiros (Cai muito!)

No Brasil (Word em PT-BR), os atalhos são traduzidos. Cuidado com o Ctrl+T!

  • Ctrl + T: Selecionar Tudo. (No Excel/inglês é Ctrl+A).
  • Ctrl + L: Localizar palavras no texto.
  • Ctrl + U: Substituir palavras.
  • Ctrl + N: Negrito.
  • Ctrl + J: Justificar o texto.
  • Ctrl + Z: Desfazer a última ação.

✏️ Notas e Dicas do Professor

2.3 Excel: Fundamentos das Fórmulas

  • Toda fórmula deve começar com igual (=).
  • Referência Relativa (Ex: A1): Muda sozinha ao copiar.
  • Referência Absoluta (Ex: $A$1): O cifrão TRAVA a referência.
  • Dois pontos vs Ponto e vírgula: A1:A5 = "De A1 ATÉ A5". A1;A5 = "A1 E A5".

2.4 Excel: Funções Básicas

  • =SOMA(A1:A5): Soma todos os valores.
  • =MÉDIA(A1:A5): Média aritmética. Ignora textos.
  • =MÁXIMO(A1:A5) / =MÍNIMO(A1:A5): Maior/Menor valor.

2.5 Excel: Funções Avançadas e Lógicas

  • =SE(teste; V; F): Retorna valor baseado em condição.
  • =PROCV(...): Procura um valor na vertical.
  • =CONT.NÚM(): Conta apenas números. CONT.VALORES(): Conta não vazias.

3 Redes de Computadores e Internet 🌐

3.1 Abrangência das Redes (Geográfica)

  • PAN: Rede pessoal (ex: Bluetooth).
  • LAN: Rede Local. Prédio ou campus.
  • MAN: Rede Metropolitana. Filiais na mesma cidade.
  • WAN: Longa Distância (Países/Mundo). A Internet é a maior WAN.

✏️ Notas e Dicas do Professor

3.2 Topologias Físicas

  • Estrela: Conecta a Switch central. Falha local não derruba a rede toda.
  • Barramento (Bus): Cabo central. Se romper, cai tudo.
  • Anel (Ring): Círculo. Sinal passa máquina a máquina.
  • Malha (Mesh): Todos com todos. Muito usada na internet.

3.3 Equipamentos de Rede

  • Switch: Liga PCs em LAN (Estrela). Entrega dados ao destinatário correto via MAC.
  • Roteador: Conecta redes DIFERENTES (ex: LAN à Internet). Escolhe rotas via IP.
  • Access Point (AP): Ponto de acesso Wi-Fi.

3.4 Protocolos Básicos: TCP/IP, DHCP e DNS

  • IP: É o "CPF" da máquina (IPv4 32 bits, IPv6 128 bits).
  • DNS: Transforma nomes (google.com) em IPs numéricos.
  • DHCP: Entrega endereços IP dinamicamente para as máquinas.
  • TCP vs UDP: TCP garante entrega. UDP é rápido (sem garantia).

3.5 Internet, Intranet e Extranet

  • Intranet: Rede PRIVADA. Usa os mesmos protocolos (TCP/IP)!
  • Extranet: Parte da Intranet para parceiros externos via internet.

5 Correio Eletrônico (E-mail) ✉️

5.1 Cabeçalho: Para, Cc e Cco

  • Para (To): Destinatários principais.
  • Cc: Com Cópia. Todos veem.
  • Cco: Cópia Oculta. Oculta quem está no Cco.

5.2 Responder vs Responder a Todos

  • Responder a Todos: Vai para Remetente + 'Para' + 'Cc'.
  • Atenção: Quem estava em Cco JAMAIS recebe a "resposta a todos".

5.3 Protocolos de E-mail

  • SMTP: Sua Mensagem Tá Partindo (ENVIO).
  • POP3: Baixa e APAGA do servidor.
  • IMAP: Acessa Múltiplos. Sincroniza e mantém no servidor.

7 Segurança da Informação 🛡️

7.1 Princípios Básicos (D.I.C.A)

  • Disponibilidade: Sistema deve estar acessível.
  • Integridade: Dados não alterados indevidamente.
  • Confidencialidade: Garantida pela Criptografia.
  • Autenticidade: Garantida pela Assinatura Digital.

7.2 Vírus vs Worms

  • Vírus: PRECISA de hospedeiro e de execução.
  • Worm (Verme): AUTÔNOMO. Se autorreplica e causa lentidão na rede.

7.3 Ransomware e Trojan

  • Ransomware: Criptografa dados e cobra resgate.
  • Trojan: Parece legítimo, mas abre portas (Backdoors).

7.5 Ferramentas de Segurança

  • Criptografia Simétrica: Mesma chave (rápida).
  • Criptografia Assimétrica: Par de chaves (Pública/Privada).
  • Firewall: Filtra o TRÁFEGO. NÃO escaneia vírus!

7.6 Backups e Nuvem

  • Incremental: Copia o que mudou desde o ÚLTIMO BACKUP.
  • Diferencial: Copia o que mudou desde o último Backup COMPLETO.
